# 画面設計書（Flutter UI）

## 1. 概要

ラクフクのUIは「毎朝1分で完結」をコンセプトに設計します。

### 1.1 デザイン原則

| 原則 | 説明 |
|------|------|
| ワンアクション | 1画面で1つの主要アクションのみ |
| 視認性 | 大きなカード、明確なコントラスト |
| スピード | 最小限のタップで完了 |
| フィードバック | 操作結果を即座に視覚化 |

### 1.2 カラーパレット

| 名前 | HEX | 用途 |
|------|-----|------|
| Primary | #1A365D | ナビ、ボタン |
| Secondary | #4A5568 | サブテキスト |
| Accent | #ED8936 | CTA、ハイライト |
| Background | #F7FAFC | 背景 |
| Card | #FFFFFF | カード背景 |
| Success | #48BB78 | 成功 |
| Warning | #ECC94B | 警告 |
| Error | #F56565 | エラー |

### 1.3 タイポグラフィ

| 用途 | サイズ | ウェイト |
|------|--------|----------|
| 見出し | 24sp | Bold |
| サブ見出し | 18sp | SemiBold |
| 本文 | 16sp | Regular |
| キャプション | 14sp | Regular |
| ボタン | 16sp | SemiBold |
