## 2. プロダクト概要

### 2.1 アプリ名
**ラクフク（Rakufuku）**

> 「楽」+ 「服」= 服選びを楽に

### 2.2 コンセプト
> 「朝、1分で"正解"が決まる。迷いも、妥協も、場違いもゼロ。」

毎朝の服選びの意思決定コストをゼロにする、AI搭載のパーソナルスタイリストアプリ。

### 2.3 解決する課題

| 課題 | 解決策 |
|------|--------|
| 毎朝の「何を着よう？」の迷い | AIが最適な1案を即座に提案 |
| TPOに合った服装がわからない | カレンダー・天気から自動判定 |
| 急な会食やデートでパニック | シーン別の代替案を3案まで提示 |
| クローゼットの死蔵服 | 着ていない服を優先的に提案 |

## 4. 核心機能

### 4.1 機能①：コーディネート提案

#### P0: 意思決定の完全自動化（MVP必須）

| 機能 | 詳細 |
|------|------|
| **自動条件取り込み** | 天気、気温（体感）、カレンダー予定（商談/社内/会食）、移動手段を自動取得 |
| **1分提案フロー** | 最適な1案を提示。理由は「今日は午後から雨＋商談なので、撥水靴とジャケット」のように1行で明示 |
| **ワンタップ確定** | 納得すれば「このまま行く」で終了 |
| **代替案** | スワイプで最大3案まで表示 |

#### P1: 継続的なパーソナライズ

| 機能 | 詳細 |
|------|------|
| **クイックフィードバック** | 「着た/着ない」「暑かった/寒かった」を2タップで学習 |
| **印象プリセット** | 「信頼感MAX（勝負服）」「親しみやすさ（後輩指導）」など |
| **気温変動リカバリ** | 昼夜の寒暖差が大きい日のみ、追加アイテムを通知 |

#### P2: 導入ハードルの撤廃

| 機能 | 詳細 |
|------|------|
| **クローゼット登録の省力化** | ECサイトの購入履歴連携、レシート写真からアイテム自動特定 |

---

### 4.2 機能②：自動購入・最適化（将来機能）

> 「足りないものはAIが見つける。買い物は"作業"から"資産投資"へ。」

#### P0: クローゼットの資産管理

| 機能 | 詳細 |
|------|------|
| **稼働管理（死蔵防止）** | 「この服、3ヶ月着ていません」を可視化 |
| **ギャップ購入** | 「この1着で10パターンの新コーデが可能」なROIの高い1着を特定 |

#### P1: 失敗ゼロの購買体験

| 機能 | 詳細 |
|------|------|
| **不足アイテムの提示** | コーデに足りないアイテムを明示 |
| **サイズID** | 過去の成功データからブランドごとのサイズ差を吸収 |
| **1-Click 補充決済** | 消耗品の買い替え時期をAIが検知しワンタップ発注 |

## 5. 顧客価値

### 5.1 CX（カスタマーエクスペリエンス）

| 価値 | 詳細 |
|------|------|
| **1分以内の最適解** | アプリを開くだけで「今日の正解コーデ」が提示される |
| **失敗のない拡張** | 手持ちの服と相性が良く、サイズも完璧なアイテムだけをレコメンド |

### 5.2 感情的価値

| 感情 | 詳細 |
|------|------|
| **確信** | 「今日の自分は大丈夫」という揺るぎない安心感と自信 |
| **解放** | 毎朝の「何を着よう？」というノイズからの解放 |
| **発見** | 自分では選ばなかったが、実は似合う服との出会い |

## 6. 技術スタック（採用予定）

### 6.1 ハッカソン要件との対応

| 要件カテゴリ | 採用技術 | 理由 |
|-------------|---------|------|
| **実行環境** | Cloud Run | コンテナベースでスケーラブル、コスト効率が良い |
| **AI技術** | ADK + Gemini 2.0 Flash | エージェント構築に最適、Vertex AI経由で利用 |
| **AI技術** | Vision AI | 服の自動カテゴリ分類 |

### 6.2 全体構成

| レイヤー | 技術 |
|---------|------|
| フロントエンド | Flutter（iOS/Android両対応） |
| バックエンド | Python + FastAPI + ADK |
| データベース | Firestore |
| 画像ストレージ | Firebase Storage |
| 認証 | Firebase Authentication |
| 外部連携 | OpenWeather API, Google Calendar API |
