# Rakufuku（ラクフク） 動画コンテンツ 要素集

> 対象: 第4回 Agentic AI Hackathon with Google Cloud
> 用途: YouTube動画・ハッカソンデモ動画に盛り込むべき要素の整理

---

## 1. 公式審査基準と動画で伝えるべきこと

### 審査3軸 → 動画での伝え方

| 審査軸 | 動画で伝えるべきメッセージ | 伝え方 |
|--------|------------------------|--------|
| **課題の新規性** | 「毎朝10分、年間60時間。服選びは多変数最適化問題」 | 冒頭の共感フック。視聴者が「自分もそうだ」と思う導入 |
| **解決策の有効性** | 「4人のAIスタイリストが天気・予定・好みを全部把握して提案」 | デモ実演。実際にアプリが動く様子を見せる |
| **実装品質と拡張性** | 「Google Cloud 6技術統合、全AI機能にフォールバック」 | アーキテクチャ図1枚 + Google Cloud技術名のテロップ |

### 奨励賞5枠を意識した訴求

| 賞の方向性 | 動画内で光らせるポイント |
|-----------|----------------------|
| 課題発見賞 | 「天気×予定×手持ち服×好み = 4変数同時最適化。人間の脳が苦手でAIが得意な領域」 |
| アイデア賞 | 「4人のAIスタイリストチーム」という擬人化メタファーの印象的な提示 |
| 実装賞 | Google Cloud 6技術の活用箇所を一覧テロップで見せる |

## 2. 動画タイトル案

### ハッカソン/Agentic AI文脈

1. **「4人のAIスタイリストが毎朝コーデを提案してくれるアプリを作った【Google Cloud Hackathon】」**
2. **「Gemini + Imagen 4 で"朝の10分"をゼロにする ── マルチエージェントコーデ提案アプリ」**
3. **「天気 x カレンダー x クローゼット x AI = Rakufuku【Agentic AI Hackathon】」**
4. **「4つのAIエージェントが並列でコーデを考える仕組み【Vertex AI / Google ADK】」**
5. **「マルチエージェントが本気でコーデを考えるとこうなる【第4回 Google Cloud ハッカソン】」**

### 一般テック視聴者文脈

6. **「もう朝、服で悩まない。AIが毎日5パターン提案してくれるアプリ」**
7. **「全身写真を撮るだけでコーデ診断＆クローゼット登録できるAIアプリ」**
8. **「スワイプするだけでAIが学習。あなた専用のスタイリストに育つアプリ」**
9. **「クローゼットの服 + 天気 + 予定 = 今日のベストコーデをAIが決める」**
10. **「朝の10分を、30秒に。AIファッション提案アプリの実力」**

## 4. デモで見せるべき画面と伝えるメッセージ

### シーン1: コーデ提案フロー

| 項目 | 内容 |
|------|------|
| **画面** | ホーム画面。天気情報（気温・天候アイコン）、カレンダー連携表示、ローディング → 5つのコーデカード表示 |
| **伝えるメッセージ** | 「天気も予定も自動取得。ユーザーはアプリを開くだけ」 |
| **テロップ案** | 「天気 x 予定 x クローゼット = 最適コーデ」 |
| **技術名の明示** | OpenWeather API / Google Calendar API / Gemini 2.0 Flash |

### シーン2: 4つのAIスタイリストの提案

| 項目 | 内容 |
|------|------|
| **画面** | 5枚のコーデカード。各カードにスタイルラベル（カジュアル/フォーマル/バランス/トレンド）、AIスコア、「おすすめ」バッジ |
| **伝えるメッセージ** | 「4人のAIスタイリストがそれぞれの視点でコーデを考え、指揮者AIがベスト5を選出」 |
| **テロップ案** | 「4人のAIスタイリスト: Casual / Formal / Balanced / Unique」 |
| **技術名の明示** | Gemini 2.0 Flash（4エージェントの思考エンジン）/ asyncio.gather並列実行 |

### シーン3: マネキン画像

| 項目 | 内容 |
|------|------|
| **画面** | コーデカードのマネキン画像をクローズアップ。複数コーデの画像を並べて比較 |
| **伝えるメッセージ** | 「AIが提案したコーデをフォトリアルに可視化。着用イメージが一目でわかる」 |
| **テロップ案** | 「Imagen 4 Fast でAI生成」 |
| **技術名の明示** | Imagen 4 Fast（Vertex AI）/ Cloud Storage |

### シーン4: コーデ診断

| 項目 | 内容 |
|------|------|
| **画面** | (1) 全身写真アップロード → (2) 分析ローディング → (3) スコア表示（7.5/10等） → (4) 良い点・改善点 → (5) アイテム検出（クロップ画像つき）→ (6) クローゼット登録 |
| **伝えるメッセージ** | 「写真1枚でコーデ診断 + クローゼット自動登録。手入力不要」 |
| **テロップ案** | 「撮るだけ診断」「4段階AIパイプライン」 |
| **技術名の明示** | Gemini 2.5 Flash / Cloud Vision API / PILクロップ |

### シーン5: スワイプ操作と学習

| 項目 | 内容 |
|------|------|
| **画面** | 左右スワイプで閲覧 → 上スワイプで決定 → 「今日のコーデ」確定画面 |
| **伝えるメッセージ** | 「スワイプするだけでAIが好みを学習。使うほどあなた専用のスタイリストに」 |
| **テロップ案** | 「スワイプ = AI学習」「使うほど精度UP」 |
| **技術名の明示** | EMA（指数移動平均）嗜好学習 / Firestore |

## 6. 視覚要素

### サムネイル案

#### 案A: 「Before/After」型
- **ビジュアル**: 左半分 - クローゼットの前で悩む人（暗め）、右半分 - アプリ画面（マネキン画像付き、明るい）
- **テキスト**: 「朝の10分を、30秒に。」
- **配色**: 左側グレー → 右側ブランドカラー

#### 案B: 「4エージェント」型
- **ビジュアル**: 4分割画面にそれぞれ異なるスタイルのマネキン画像。中央にアプリロゴ
- **テキスト**: 「4人のAIスタイリスト」
- **配色**: 各エージェントのテーマカラー（カジュアル=アース、フォーマル=ネイビー、バランス=グレー、トレンド=ラベンダー）

#### 案C: 「数字インパクト」型
- **ビジュアル**: 大きく「10分 → 30秒」の数字。背景にアプリ画面
- **テキスト**: 「AIが毎朝コーデを決める」
- **配色**: Google Cloudブランドカラー基調

### アーキテクチャ図（テロップ/スライド用）

```
  ユーザーの情報
 [天気] [予定] [クローゼット] [好み]
          |
          v
  ┌─────────────────────┐
  │  Orchestrator (指揮者AI) │
  └─────────┬───────────┘
      ┌─────┼─────┬─────┐
      v     v     v     v
   [Casual] [Formal] [Balance] [Unique]

      │     │     │     │
      └──┬──┘     └──┬──┘

         |
         v
     Imagen 4 Fast → マネキン画像生成
```

## 9. 注意点・避けるべきこと

| 避けるべきこと | 理由 | 代わりにやること |
|--------------|------|----------------|
| 技術説明から入る | 審査員含め視聴者が離脱する | まず課題共感 → デモ → 技術の順 |
| 「ChatGPTでもできる」と思われる | 差別化が伝わらない | 「4人のAIスタイリスト」「並列実行」を明確に |
| Google Cloud技術名を言わない | 審査要件の充足が不明確に | テロップ + 口頭で6技術を明示 |
| デモなしでスライドだけ | 「本当に動くの？」と思われる | 最初の30秒で動くアプリを見せる |
| 全機能を詰め込む | 散漫になる | 「コーデ提案」を主軸に、他はサブ |
